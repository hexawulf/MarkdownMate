## Retaking `editor-interface.png`

1. Open https://markdownmate.org (or `npm run dev`) at a 1600×900 window.
2. Create a document with a heading, a task list, a table, a code block and some math.
3. Switch to **Split** view and put the cursor on line 1.
4. Take a screenshot of the window and save it as `docs/screenshots/editor-interface.png`.

Use sample content only. Never take a screenshot of real documents.
